A rhythm platformer with 15 hand-authored levels across four movement modes, every obstacle placed on the beat. The visuals are entirely procedural — neon over a generated Persian girih lattice — so the build contains no art assets.

02 Open source

Packages on pub.dev.

Small, sharp libraries for problems I hit while building the products above.

  • pardakht

    One type-safe API across seven Iranian payment gateways, in pure Dart. Built around the failure modes that cost merchants money: a money type that makes the Rial/Toman mix-up unrepresentable, a first-class “already verified” status, server-side verification with a proxy mode so no merchant key ships in an app, and retries that never repeat a session or a refund.

    • Dart
    • API design
    • Sealed types
    • Idempotency
    • ~680 tests
    pub.dev GitHub

  • psiphon_mobileproxy

    Runs a Psiphon tunnel on-device behind a local HTTP proxy (Android and iOS). Point an HTTP client or WebView at it and that traffic goes through the tunnel — no VPN permission, nothing else on the device affected. A small Go shim makes stop() really disconnect and gives start() a timeout; prebuilt Go Mobile binaries are rebuilt and verified in CI on every change.

    • Dart
    • Kotlin
    • Swift
    • Go Mobile
    • GitHub Actions
    pub.dev GitHub

  • outline_mobileproxy

    Wraps the Outline SDK’s Mobileproxy library: a local on-device HTTP proxy backed by Shadowsocks, SOCKS5 or an auto-selecting Smart Dialer, again with no VPN permission. Ships prebuilt Go Mobile binaries with a reproducibility-focused CI pipeline that rebuilds and verifies them. Apache-2.0.

    • Dart
    • Kotlin
    • Swift
    • Go Mobile
    • Integration tests
    pub.dev GitHub
