outline_mobileproxy — Flutter Plugin

A Flutter plugin wrapping the Outline SDK's Mobileproxy library: it runs a local HTTP proxy on-device (Android & iOS) backed by Shadowsocks, SOCKS5, or an auto-selecting Smart Dialer — with no VPN permissions required. Ships prebuilt Go Mobile native binaries with a reproducibility-focused CI pipeline that rebuilds and verifies them on every change.

Dart Kotlin Swift Go Mobile Networking GitHub Actions CI Integration Tests
