Open Source · Dart Package · 2026

pardakht — One API Across Iranian Payment Gateways

Iranian payment providers each ship their own thin wrapper, so switching provider means rewriting the integration. pardakht puts one type-safe interface across seven of them, in pure Dart with no Flutter dependency. It is built around the failure modes that cost merchants money: a money type that makes the Rial/Toman mix-up unrepresentable, a first-class “already verified” status, server-side verification with a proxy mode so no merchant key ships in an app, and retries that never repeat a session or a refund. ~680 tests.

Dart (no Flutter) Payment Gateways API Design Sealed Types Idempotency Security Backend (shelf) 680+ Tests

Open Source · Flutter Plugin · 2026

psiphon_mobileproxy — Flutter Plugin

A Flutter plugin that runs a Psiphon tunnel on-device behind a local HTTP proxy (Android & iOS). Point an HTTP client or WebView at the returned address and that traffic goes over the tunnel — no VPN permission required, and nothing else on the device is affected. It ships a small Go shim so stop() really disconnects and start() takes a timeout, with prebuilt Go Mobile binaries that CI rebuilds and verifies on every change.

Dart Kotlin Swift Go / Go Mobile Networking Supply-chain Provenance GitHub Actions CI

Open Source · Flutter Plugin · 2026

outline_mobileproxy — Flutter Plugin

A Flutter plugin wrapping the Outline SDK's Mobileproxy library: it runs a local HTTP proxy on-device (Android & iOS) backed by Shadowsocks, SOCKS5, or an auto-selecting Smart Dialer — with no VPN permissions required. Ships prebuilt Go Mobile native binaries with a reproducibility-focused CI pipeline that rebuilds and verifies them on every change. Apache-2.0, and the sibling of psiphon_mobileproxy above.

Dart Kotlin Swift Go Mobile Networking GitHub Actions CI Integration Tests
